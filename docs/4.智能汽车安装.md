完成上述步骤后，必须要调整舵机角度到90度，才能继续以下步骤。

调整舵机代码如下：

```c
#include <Servo.h>  // 包含舵机库

Servo myservo;  // 创建舵机对象

void setup() {
  myservo.attach();  // 将舵机信号线连接到数字引脚9（可以根据实际连接修改）
  myservo.write(90);  // 设置舵机初始位置为90度
  
  delay(1000);  // 等待1秒让舵机有时间转动到指定位置
}

void loop() {
  // 这里不需要做任何事情
}
```
